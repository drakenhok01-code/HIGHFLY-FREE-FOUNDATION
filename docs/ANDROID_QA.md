# Protocolo QA: Samsung S23 Ultra horizontal

1. Abrir https://drakenhok01-code.github.io/HIGHFLY-FREE-FOUNDATION/ después de Actions exitoso. Habilitar horizontal y fullscreen; verificar viewport visible, ausencia de scroll y carga del mundo original.
2. Comparar las mismas montañas, agua, caminos, ciudades, vegetación, puentes, colisiones y distancias con Unsung SHA fijado. Ninguna mejora de FPS permite degradar el mapa.
3. Joystick 360°/diagonales/retorno, cámara libre derecha, ATK 1/2/3 con enemigo y vida, salto, rodamiento con colisión, nadar/entrar y salir del agua, USAR. Dashboard solo durante juego, no HOME.
4. Bruma: borrar preferencia, recargar y medir diferencia entre 0%, 35%, 100% con captura **del mismo punto y hora del juego**; revisar conflictos entre FogPass, volumen, SSAO y profundidad WebGL.
5. Probar 3 sesiones de 5 min, Google Chrome Android, multitouch simultáneo, cambios de fullscreen y rotación; inspeccionar ausencia de errores WebGL/context lost, FPS real y temperatura.
6. Marcar cada caso PASS/FAIL/BLOCKED, aportar captura/video y versión de commit; nunca confundir QA estático con 3D verdadero.
